## Xdebug {#xdebug_title}

Salah satu alat yang paling berguna dalam pengembangan perangkat lunak adalah debugger yang tepat. 
Alat ini memungkinkan Anda melacak eksekusi kode dan memantau konten tumpukan. Xdebug, debugger PHP, 
dapat digunakan oleh berbagai IDE untuk menyediakan Breakpoint dan inspeksi tumpukan (_stack_). 
Alat ini juga dapat memungkinkan alat seperti PHPUnit dan KCacheGrind untuk melakukan analisis cakupan kode (_code coverage
analysis_) dan pembuatan profil kode (_code profiling_).

Jika Anda mengalami kesulitan, dan ingin menggunakan `var_dump()`/`print_r()`, dan Anda tetap tidak dapat menemukan solusinya -
mungkin Anda perlu menggunakan debugger.

[Memasang Xdebug][xdebug-install] bisa jadi rumit, tetapi salah satu fitur terpentingnya adalah "Debugging Jarak Jauh" - 
jika Anda mengembangkan kode secara lokal lalu mengujinya di dalam VM atau di server lain, 
Debugging Jarak Jauh adalah fitur yang sebaiknya Anda aktifkan segera.

Secara tradisional, Anda akan memodifikasi Apache VHost atau file .htaccess Anda dengan nilai-nilai ini:

{% highlight ini %}
php_value xdebug.remote_host 192.168.?.?
php_value xdebug.remote_port 9000
{% endhighlight %}

"Remote host" dan "remote port" akan sesuai dengan komputer lokal dan port tempat Anda mengonfigurasi IDE untuk
mendengarkan. Kemudian, Anda tinggal menempatkan IDE Anda ke mode "mendengarkan koneksi", dan memuat URL:

    http://your-website.example.com/index.php?XDEBUG_SESSION_START=1

IDE Anda sekarang akan mencegat status terkini saat skrip dijalankan, yang memungkinkan Anda mengatur 
titik henti (_breakpoint_) dan menguji nilai dalam memori.

Graphical debuggers make it very easy to step through code, inspect variables, and eval code against the live runtime.
Many IDEs have built-in or plugin-based support for graphical debugging with Xdebug. MacGDBp is a free, open-source,
stand-alone Xdebug GUI for macOS.

Debugger grafis memudahkan Anda untuk menelusuri kode, memeriksa variabel, dan mengevaluasi kode terhadap runtime langsung.
Banyak IDE memiliki dukungan bawaan atau berbasis plugin untuk debugging grafis dengan Xdebug. 
MacGDBp adalah GUI Xdebug sumber terbuka gratis dan mandiri untuk macOS.
